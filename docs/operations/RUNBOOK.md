# SentinelX Operations Runbook

## 1. Daily Operations Checklist

1. **Verify Backend Health**: Check `https://<api-domain>/health`.
2. **Review Open Incidents**: Triage new incidents on the SOC Dashboard.
3. **Execute AI Threat Analysis**: Run OpenRouter analysis on untriaged critical incidents.
4. **Deploy Containment Actions**: Stage and mark response actions completed for verified threats.
5. **Generate Daily PDF Reports**: Download executive incident reports for management sign-off.
