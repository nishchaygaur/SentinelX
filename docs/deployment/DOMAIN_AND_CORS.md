# SentinelX — Domain Configuration & CORS Whitelisting

## 1. CORS Enforcement in Production

When the frontend and backend are hosted on separate domains (e.g. `sentinelx.vercel.app` and `sentinelx-api.onrender.com`), cross-origin requests must be explicitly authorized.

In Render Dashboard, set:
```env
CORS_ORIGIN=https://sentinelx.vercel.app
```

---

## 2. Dynamic Vercel Previews

SentinelX automatically permits preview deployments generated by Vercel for pull requests:
```javascript
if (/^https:\/\/[a-zA-Z0-9_-]+\.vercel\.app$/.test(origin)) {
    return true;
}
```
