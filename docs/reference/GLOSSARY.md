# SentinelX — Cybersecurity & Platform Glossary

| Term | Definition |
|---|---|
| **Alert** | A security notification generated by the detection rules engine when log events violate defined defensive thresholds. |
| **Incident** | A correlated security case file aggregating one or more high-priority alerts for formal SOC investigation and containment. |
| **IoC** | Indicator of Compromise: An observable artifact (IP address, domain, file hash, CVE) associated with known malicious activity. |
| **MITRE ATT&CK** | A globally-accessible knowledge base of adversary tactics and techniques based on real-world observations. |
| **Normalization** | The process of parsing heterogeneous, multi-vendor log formats into a standardized, structured schema. |
| **Risk Score** | A deterministic 0–100 integer score computed from alert severity, confidence, threat intelligence, frequency, and technique impact. |
| **Simulated Response** | A defensive containment workflow (e.g. firewall block, host isolation) executed in sandbox/audit mode without disrupting production networks. |
| **Sliding Window** | A time-bounded evaluation window (e.g., 5 minutes) used by detection algorithms to correlate frequency patterns. |
| **TLP** | Traffic Light Protocol: A set of designations used to indicate sharing boundaries (e.g. TLP:AMBER for restricted internal distribution). |
| **YARA** | A tool aimed at helping malware researchers identify and classify malware samples based on textual or binary patterns. |
